# ESP8266 智能舵机控制系统

基于 ESP8266 与 Blinker 平台实现的简单物联网舵机控制项目。

通过手机 App 可远程控制舵机执行开 / 关动作，并支持实时调整舵机角度参数。系统会自动将参数保存到 EEPROM，实现断电后配置不丢失。

---

## 功能说明

### 1. 远程控制
- App 按钮控制舵机“开 / 关”动作
- 开关动作由状态机控制执行

### 2. 参数调节
首次使用前需修改以下配置：

char auth[] = "456***";   // Blinker 设备密钥
char ssid[] = "Xia***";   // WiFi 名称
char pswd[] = "123***";   // WiFi 密码
App 滑块可调整：

最大角度（max）
最小角度（min）
中间回正角度（mid）

参数修改后会立即生效，并自动写入 EEPROM。

### 3. 掉电保存
所有角度参数存储在 ESP8266 Flash（EEPROM）
设备断电重启后自动恢复上次配置

## UI 机制说明

Blinker App 的 Slider 控件属于 单向控制型组件：

App → ESP8266（控制）

而不是双向同步：

ESP8266 → App（不会自动回填）

因此存在以下行为特点：

✔ 正常行为
每次移动滑块，会触发 ESP 回调函数
ESP 更新参数并保存到 EEPROM
⚠️ UI 显示限制
App 打开时不会自动显示 ESP 当前保存值
只有当用户再次操作滑块后，界面才会更新为实际值

### 系统中的唯一数据源为：

EEPROM（Flash 存储） → servo_cfg

工作流程如下：

设备启动后从 EEPROM 读取参数
App 调整滑块后更新参数
参数自动写入 EEPROM
舵机动作始终使用最新保存参数
App 重新打开后，需再次触发滑块事件以刷新显示

## 使用建议
初次使用或设备重启后：
点击任意滑块一次以同步 UI 显示状态
日常使用：
直接使用“开 / 关”按钮即可
参数无需频繁调整
